# Аудит m3etis.is-a.dev — итерация 2

Дата: 6 ноября 2026. Объект: текущая Astro-сборка (`http://localhost:4322`, рабочая копия, не задеплоена).
Новая цель: резюме-визитка для позиции **AI Product Engineer / Frontend Engineer** в сдержанном премиальном стиле, вдохновлённом дизайн-языком Apple.

Аудит первой итерации (одностраничный HTML на Tailwind CDN) хранится локально в `design/PORTFOLIO_AUDIT_v1.md`; папка `design/` не публикуется.

## 3. Контент и позиционирование

1. **Роль не совпадает с целью.** Сейчас «Senior Frontend Engineer / AI Automation & Enablement», цель — «AI Product Engineer / Frontend Engineer».
2. **Hero рассказывает биографию, а не ценность.** Абзац начинается с «20+ лет в вебе» и пути от сисадмина. За 10–15 секунд не видно главного: я соединяю процессы, интеграции, модель и UI в продукт.
3. **Нет секции «Что я делаю».** Компетенции разбросаны по «Чем отличаюсь», навыкам и карточкам проектов.
4. **AI UX почти не виден, хотя это самое сильное, что есть.** В репозиториях подтверждено больше, чем показано на сайте:
   - **ОНК 2.0:**
     - ИИ готовит черновик, в выводы и предписания попадает только то, что принял или исправил администратор (human-in-the-loop);
     - норма в выводе должна ссылаться на фрагмент базы знаний, а цитата — дословно совпадать (проверка источников);
     - ответ строго по JSON Schema;
     - персональные данные удаляются до модели;
     - у каждого запуска сохраняются модель, версия промпта и снимок базы знаний;
     - чат с данными через инструменты только на чтение (агент с tool calling) и журнал;
     - гибридный поиск: полнотекстовый + векторный, pgvector;
     - фоновые задачи;
     - выбор модели с оценкой «подходит ли компьютеру»;
     - замер: анализ посещения на Apple M4 / 16 ГБ — около 110 секунд, оба основания подтверждены цитатами.
   - **Offline Sales Analytics:**
     - стриминг токенов по WebSocket, прогресс SQL, отмена запроса, уточняющие вопросы;
     - SQL виден в ответе;
     - лайки и дизлайки со статистикой, кнопка повтора;
     - статус сервисов (бэкенд и Ollama);
     - голосовой ввод, экспорт в DOCX;
     - валидация SQL (только SELECT/WITH).
5. **Проекты перегружены текстом.** Задача и решение — абзацы по 3–5 строк. На мобильном карточка около 1700 px. Карусель показывает один проект из четырёх: для беглого просмотра это минус.
6. **«Обо мне» дублирует «Опыт».** Биография рассказана дважды.
7. **Навыки сгруппированы по технологиям, а не по задачам.** Цель — Frontend, AI & Automation, Integrations, Tooling & Practices. Около 40 чипов создают визуальный шум.
8. **Опыт:** роли 2006–2016 занимают столько же места, сколько текущая работа. В Alem.AI один пункт «Фронтенд-разработка».

## 4. Визуальные проблемы относительно новой цели

| Проблема | Где |
| --- | --- |
| Тёплая «бумажная» палитра с оранжевым акцентом и редакционная подача не соответствуют Apple-inspired минимализму | `tokens.css` |
| Моноширинный шрифт используется как декор: номера секций, метки, чипы, подписи, мета-строка Hero | SectionHeader, SkillChip, Hero, Pipeline |
| Body 16 px — меньше целевых 17–18 px | `--text-body` |
| Все секции на одном фоне, нет ритма white → off-white → dark | все секции |
| Иерархия держится на рамках: у карточек, ячеек, шагов, контактов, чипов везде border | компоненты |
| Плотность: в одной карточке проекта 4 подписи, 4 блока текста, 7 чипов и 3 ссылки | ProjectCard |
| Пунктирные блоки («Код закрыт», TODO) выглядят как черновик | EmptyState, `.todo` |

## 5. Технические проблемы

| Метрика | Значение | Комментарий |
| --- | --- | --- |
| Lighthouse desktop | 100 / 100 / 100 / 100 | FCP 0.4 s, LCP 0.5 s, CLS 0 |
| Lighthouse mobile | 97 / 100 / 100 / 100 | FCP 2.0 s, LCP 2.1 s (эмуляция, preview без gzip) |
| Вес страницы | 193 KB | из них шрифты Onest и JetBrains Mono; системный стек их уберёт |
| DOM | 805 элементов | карусель и диаграммы |
| Высота страницы на 320 px | 11 340 px | длинная из-за карточек проектов |
| **Масштаб текста 200 %** | **горизонтальный overflow** | шапка (язык, тема, бургер) не переносится. WCAG 1.4.4 / 1.4.10 |

Анимации, нарушающие новые ограничения:
- **Длительности выше 350–500 мс:** вход 700 мс, линия заголовка 900 мс, фото 1.1–1.2 с, смена темы 550 мс.
- **Бесконечные анимации:** бегущая точка и подсветка шагов схемы (на паузе вне экрана), спиннер скелетона (6 повторов).
- **Анимация layout-свойства:** точка схемы двигается через `left`, а не `transform`.
- **Спотлайт под курсором** на множестве поверхностей — визуальный шум.

Что уже хорошо и сохраняется: semantic HTML и landmarks, skip link, видимый focus, `prefers-reduced-motion`, контент виден без JS, AA-контраст, RU/EN, SEO (canonical, hreflang, OG, JSON-LD, sitemap, robots, 404), CV-PDF.

## 6. Приоритизированный план редизайна

**P0 — позиционирование и структура** (после согласования)
1. Роль «AI Product Engineer / Frontend Engineer», новый Hero: заголовок, подзаголовок, абзац ценности, CTA «Посмотреть проекты».
2. Новая секция «Что я делаю»: 3 области × 3–4 подтверждённых примера.
3. Кейсы с акцентом на AI UX: короче текст, интерфейсный превью, блок «AI UX» с подтверждёнными паттернами.
4. Убрать «Обо мне» как отдельную секцию: короткое био — в Hero или «Опыт».
5. Навыки по областям: Frontend, AI & Automation, Integrations, Tooling & Practices.

**P1 — визуальный язык**
6. Новая дизайн-система: нейтральная палитра, один акцент, системный шрифт, body 17 px, шкала Display → Caption.
7. Ритм фонов секций, меньше рамок, иерархия через размер, вес и пространство.
8. Hero-визуал: UI-фрагмент «ИИ-прогона» (стриминг, проверка цитат, решение человека) вместо схемы с бегущей точкой.

**P2 — движение и качество**
9. Микроанимации в рамках 150–350 мс (вход Hero до 500 мс), только `transform`/`opacity`, без бесконечных анимаций.
10. Шапка, устойчивая к 200 % масштабу текста.
11. Обновить OG-картинки, JSON-LD и CV-PDF под новую роль; `PORTFOLIO_CHANGELOG.md`.
