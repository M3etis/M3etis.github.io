## 2. Дизайн-система

**Токены** — `src/styles/tokens.css`, два слоя: примитивы и семантические токены.
- **Поверхности:**
  - светлая тема: `#FFFFFF` и `#F5F5F7`;
  - тёмная тема: `#000000` и `#0B0B0C`, surface `#161618` / `#1C1C1F`;
  - тёмная «сцена» для проектов (`data-surface="stage"`) переопределяет токены локально, поэтому компонентам внутри не нужны отдельные варианты.
- **Текст:**
  - светлая тема: primary `#111113`, secondary `#5F5F66`, tertiary `#6C6C73`;
  - тёмная тема: `#F5F5F7`, `#A1A1A8`, `#8E8E95`.
- **Акцент:**
  - текст и ссылки: `#0066E6`, в тёмной теме `#3B8BFF`;
  - заливка кнопок: `#0066E6`, в тёмной теме `#0A6CFF` (белый текст 4.56:1).
- **Семантические цвета:**
  - светлая тема: success `#157A3C`, warning `#9E5200`, danger `#C4281B`;
  - тёмная тема: `#4CC38A`, `#F5A524`, `#FF6B5E`.
- **Типографика:**
  - системный стек `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", Roboto, "Helvetica Neue", Arial`;
  - шкала: Display 38→64 px, H1 34→56, H2 28→48, H3 20→24, Lead 19→21, Body 17, Caption 13, Mono 13;
  - трекинг от −0.035em на Display до −0.015em на H3;
  - моноширинный шрифт — только для кода, номеров областей и технических меток.
- **Отступы и сетка:**
  - шкала на 4 pt;
  - отступы секций 64→160 px;
  - контейнеры 980 px (текст) и 1200 px (сетки);
  - радиусы 8 / 12 / 18 / 28.
- **Глубина:** три уровня мягких теней. Blur только у шапки после прокрутки. Иерархия держится на смене фона, а не на рамках.

**Компоненты** (`src/components/`): Button (primary / secondary / text), Link, Card, ProjectCard (кейс), ToolCard, SkillChip (Tag), SectionHeader, TimelineItem, ContactLink, CodeBlock (подсветка SQL и SCSS, декоративный режим), CopyButton, ThemeToggle, Skeleton, EmptyState, Icon (Lucide 1.75 + Simple Icons), LangSwitch, Todo, AiRunCard, `previews/OsaChatPreview`, `previews/OnkReviewPreview`.

Анимируются только `transform`, `opacity` и `clip-path` (для эффекта «печати»). Бесконечных анимаций нет. При `prefers-reduced-motion: reduce` движение отключено, контент виден сразу. Параллакс и эффекты за курсором намеренно не добавлены.

# Итерация 3: новый Hero и движение по мотивам ClamKeep

Отзыв: блок-демонстрация справа в Hero перегружен плотным текстом, визуал не работает; Hero нужно переработать полностью и взять идеи переходов с лендинга ClamKeep (`m3etis.is-a.dev/ClamKeep/`).

## Что взято из ClamKeep

ClamKeep — одна страница на GSAP + ScrollTrigger. Переносим приёмы, а не библиотеку: всё сделано на CSS и примерно 4 KB собственного JS, поэтому GSAP (~42 KB в сжатом виде) не понадобился.

| Приём в ClamKeep | Как реализовано здесь |
| --- | --- |
| Заголовок раскрывается по строкам из-под маски (`.line` / `.line-in`, expo-кривая) | `.mask > span`, кривая `--ease-expo`. В Hero — при загрузке, в заголовках секций — при появлении (`data-reveal="lines"`) |
| Вступление Hero по таймлайну: надзаголовок → строки → лид → кнопки → мета и чипы → продукт поднимается с 3D-наклоном | CSS-каскад с задержками; «окно продукта» поднимается с `rotateX(16deg)` и перспективой |
| MacBook закреплён при прокрутке, крышка закрывается, появляется карточка статуса | «Окно продукта» закреплено (`position: sticky`, трек 240vh). Прокрутка проигрывает запрос: вопрос → интент → проверенный SQL → график → стриминг ответа → оценка; выноски появляются по шагам |
| Карточки всплывают пачкой (`y: 70`, `scale: 0.96`, expo, stagger) | `data-reveal="card"`: 56 px, 0.96 → 1, 900 мс, каскад 90 мс |
| Мини-демо в карточках, которые крутятся только на экране | Пиктограммы в «Что я делаю»: документ → проверка, модель с источниками, стриминг ответа и лайк. Работают через IntersectionObserver, за пределами экрана стоят на паузе |
| Магнитные кнопки, только для точного указателя | `data-magnetic`: смещение к курсору до ~25% размера кнопки; только при `hover: hover` и ширине от 768 px |
| Параллакс иконки в CTA | Лёгкий параллакс (±28 px) у превью кейсов и портрета в «Опыте» |
| Режимы `full` и `lite` (gsap.matchMedia) и пауза при скрытой вкладке | Сценарий закрепления только при ширине от 1024 px и высоте от 640 px; на телефоне то же проигрывается один раз при появлении; при `prefers-reduced-motion` сразу показывается финальное состояние |

## Длительности анимаций

Ради «живости» в духе ClamKeep крупные появления длиннее прежнего правила «150–350 мс»:
- строки заголовков — 900–1100 мс;
- карточки — 900 мс;
- подъём окна — 1200 мс.

Все они используют мягкую expo-кривую, анимируют только `transform`/`opacity`/`clip-path` и проигрываются один раз. Hover, нажатия и смена состояний остались в пределах 150–450 мс. Бесконечные циклы есть только у маленьких пиктограмм и индикатора набора, и только пока они видны на экране.
