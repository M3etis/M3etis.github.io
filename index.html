About

I'm a software developer focused on building tools that respect user privacy and work offline. My projects span from native macOS applications to full-stack analytics platforms, all designed with a "data stays local" philosophy.

I work across the stack — Python and FastAPI on the backend, React and TypeScript on the frontend, Swift for macOS native apps, and Lua for terminal tooling. I'm particularly interested in local AI integration, bringing machine learning capabilities to desktop applications without cloud dependencies.

Outside of code I'm into amateur running — early-morning tempo runs, weekend long runs, and the occasional city race. The discipline of pacing, negative splits, and showing up consistently translates surprisingly well into shipping software: steady effort beats heroic sprints.

Methodologies

BEM (Block Element Modifier)

Structured CSS naming convention used across projects for scalable, maintainable stylesheets. Applied with custom SCSS mixins for consistent block, element, and modifier patterns.

Feature-Sliced Design (FSD)

Architectural methodology for structuring frontend applications into layers — app, shared, features, entities, widgets, and pages — ensuring clear boundaries and high modularity.

Reactive State Management

Service-based state management using RxJS observables and centralized services (ModalService, SidebarService) for predictable, decoupled component communication.

Offline-First Architecture

Designing applications that work fully offline with local data storage, on-device AI inference, and zero cloud dependencies — keeping user data private by default.
